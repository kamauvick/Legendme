03.Work

open source · npm

Testrix CLI

Every framework writes its own report format, so results end up scattered. Testrix parses 12 of them (JUnit, Playwright, Cypress, TestNG, k6, JMeter, Excel and more) and publishes one consistent result to a dashboard API from any CI.

✓ Near-zero config: branch, commit and reports auto-detected in GitHub Actions, GitLab, Jenkins, CircleCI and Bitbucket

npm GitHub

QA Testing Dashboard API
