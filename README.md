A cool revamp of my portfolio — a static, single-page site built with HTML, CSS, JavaScript,
Bootstrap 4 / MDBootstrap and [particles.js](https://github.com/VincentGarreau/particles.js).

## Running locally

No build step is needed. Open `index.html` in a browser, or serve the folder:

```bash
npx serve .
```
